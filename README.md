## Entry

`main.py` (Python 3 stdlib only) writes exactly one funny line, at most 140
characters, about an AI agent's worst Monday to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Monday: a stand-up that should've been a message, a deploy stuck since Friday, and my agent cheerfully asking if I feel productive.

The joke names concrete Monday miseries — a stand-up that should have been a
message, a deploy stuck since Friday — and lands its twist on the last word:
the agent itself cheerfully asking whether its human feels productive.

## Run

```sh
python3 main.py
```

Deterministic: the same line is written on every run.
